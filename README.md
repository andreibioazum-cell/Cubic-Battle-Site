# Cubic Battle 4

Одностраничный сайт игры Cubic Battle 4 с событием «YA — YourAnswer»: модальное окно с формой ника, опросом на время и выдачей эксклюзивного куба. Статический проект: сборка и сторонние библиотеки не нужны — откройте `index.html` или разместите папку на любом статическом хостинге.

## Структура

```text
index.html                 Разметка и контент страницы
assets/
├── css/
│   ├── base.css            Переменные, базовые стили и типографика
│   ├── layout.css          Сетка страницы и секции (шапка, герой, футер)
│   ├── components.css      Кнопки, карточки, модальное окно и опрос
│   └── responsive.css      Адаптация для телефонов
└── js/
    └── event-quiz.js       Логика события: модалка, таймер и опрос
```

Стили разделены по назначению, а JavaScript вынесен из разметки в отдельный файл. Внешние библиотеки и сборщик не используются; из внешних ресурсов подключается только шрифт Roboto (Google Fonts).
