# Cubic Battle

Одностраничный сайт игры Cubic Battle. Статический проект: сборка и сторонние библиотеки не нужны — откройте `index.html` или разместите папку на любом статическом хостинге.

## Структура

```text
index.html                 Разметка и контент страницы
assets/
├── css/
│   ├── base.css            Переменные, базовые стили и типографика
│   ├── layout.css          Сетка страницы и секции
│   ├── components.css      Кнопки, карточки и элементы интерфейса
│   └── responsive.css      Адаптация для телефонов и планшетов
├── images/
│   ├── cubic-battle-logo.png
│   └── gameplay-screenshot.png
└── js/
    └── navigation.js      Доступное мобильное меню
```

Стили разделены по назначению, а изображения и JavaScript вынесены из корня проекта. Внешние шрифты, библиотеки и сборщик не используются.
